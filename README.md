# proyecto-java-gestion-productos# Proyecto Java - Gestión de Productos

Preentrega del Trabajo Final Integrador.

## Descripción

Aplicación desarrollada en Java para la gestión de productos y pedidos.

## Funcionalidades

- Alta de productos
- Listado de productos
- Búsqueda de productos
- Actualización de productos
- Eliminación de productos
- Creación de pedidos
- Control de stock
- Excepciones personalizadas

## Tecnologías

- Java
- Programación Orientada a Objetos (POO)
- ArrayList
- Git
- GitHub
